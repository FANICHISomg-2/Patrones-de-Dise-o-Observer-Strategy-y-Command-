# LP3 - Sesión 11: Patrones de Diseño (Observer, Strategy, Command)
UCSM - EPIS - Lenguajes de Programación III

Cada ejercicio está en su propio paquete (clase `Main`):
1. `ej1_observer` - Sistema de notificaciones (Observer)
2. `ej2_strategy` - Estrategias de descuento con menú (Strategy)
3. `ej3_command` - Control remoto de TV con 5 funciones + deshacer (Command)
4. `ej4_combinado` - Tienda en línea que combina los tres patrones

Requiere Java 16 o superior (el ejercicio 4 usa `record`).
