EJERCICIO 1: Sistema de notificaciones (Observer)

Enunciado: usuarios registrados reciben notificaciones de promociones o actualizaciones de productos; pueden suscribirse y desuscribirse dinámicamente.

Rol del patrónClase / interfaz
ObserverObservador (método actualizar)
Observer concretoUsuario
SubjectCentroNotificaciones (suscribir, desuscribir, publicar)
Dato del eventoNotificacion

Código (src/ej1_observer/Main.java):

package ej1_observer;

import java.util.ArrayList;
import java.util.List;

interface Observador { void actualizar(Notificacion n); }

class Notificacion {
    private final String tipo, mensaje;
    Notificacion(String tipo, String mensaje) { this.tipo = tipo; this.mensaje = mensaje; }
    String getTipo() { return tipo; }
    String getMensaje() { return mensaje; }
}

class Usuario implements Observador {
    private final String nombre;
    Usuario(String nombre) { this.nombre = nombre; }
    String getNombre() { return nombre; }
    public void actualizar(Notificacion n) {
        System.out.println("   -> " + nombre + " recibio [" + n.getTipo() + "]: " + n.getMensaje());
    }
}

// Subject: el centro de notificaciones mantiene la lista de suscriptores
class CentroNotificaciones {
    private final List<Observador> suscriptores = new ArrayList<>();
    void suscribir(Observador o) { if (!suscriptores.contains(o)) suscriptores.add(o); }
    void desuscribir(Observador o) { suscriptores.remove(o); }
    void publicar(Notificacion n) {
        System.out.println("Publicando " + n.getTipo() + " a " + suscriptores.size() + " suscriptor(es)");
        for (Observador o : suscriptores) o.actualizar(n);
    }
}

public class Main {
    public static void main(String[] args) {
        CentroNotificaciones centro = new CentroNotificaciones();
        Usuario ana = new Usuario("Ana"), luis = new Usuario("Luis"), rosa = new Usuario("Rosa");
        centro.suscribir(ana); centro.suscribir(luis); centro.suscribir(rosa);
        centro.publicar(new Notificacion("PROMOCION", "2x1 en laptops este fin de semana"));

        System.out.println("\nLuis se desuscribe");
        centro.desuscribir(luis);
        centro.publicar(new Notificacion("ACTUALIZACION", "Nuevo stock de teclados mecanicos"));

        System.out.println("\nLuis vuelve a suscribirse");
        centro.suscribir(luis);
        centro.publicar(new Notificacion("PROMOCION", "20% de descuento en accesorios"));
    }
}

EJERCICIO 2: Estrategias de descuento (Strategy)

Enunciado: calcular el precio final de un carrito con cuatro estrategias (SinDescuento, DescuentoFijo 10%, DescuentoPorcentual 30% con 2 productos iguales, DescuentoPorcentualAcumulado 50% al más barato desde 3 productos), elegidas desde un menú interactivo.

Rol del patrónClase / interfaz
StrategyEstrategiaDescuento
Estrategias concretasSinDescuento, DescuentoFijo, DescuentoPorcentual, DescuentoPorcentualAcumulado
ContextoCalculadoraDePrecios (setEstrategia, calcularTotal)
ModeloProducto

Código (src/ej2_strategy/Main.java):

package ej2_strategy;

import java.util.*;

class Producto {
    private final String nombre; private final double precio;
    Producto(String nombre, double precio) { this.nombre = nombre; this.precio = precio; }
    String getNombre() { return nombre; }
    double getPrecio() { return precio; }
    public String toString() { return nombre + " - S/ " + precio; }
}

// Strategy
interface EstrategiaDescuento {
    double calcular(List<Producto> carrito);
    String nombre();
}

class SinDescuento implements EstrategiaDescuento {
    public double calcular(List<Producto> c) { return CalculadoraDePrecios.suma(c); }
    public String nombre() { return "Sin descuento"; }
}

class DescuentoFijo implements EstrategiaDescuento {   // 10% sobre el total
    public double calcular(List<Producto> c) { return CalculadoraDePrecios.suma(c) * 0.90; }
    public String nombre() { return "Descuento fijo (10%)"; }
}

class DescuentoPorcentual implements EstrategiaDescuento {   // 30% a productos repetidos (2 o mas iguales)
    public double calcular(List<Producto> c) {
        Map<String, Integer> cant = new HashMap<>();
        for (Producto p : c) cant.merge(p.getNombre(), 1, Integer::sum);
        double total = 0;
        for (Producto p : c) total += cant.get(p.getNombre()) >= 2 ? p.getPrecio() * 0.70 : p.getPrecio();
        return total;
    }
    public String nombre() { return "Descuento porcentual (30% en 2 productos iguales)"; }
}

class DescuentoPorcentualAcumulado implements EstrategiaDescuento {   // 3 o mas: 50% al mas barato
    public double calcular(List<Producto> c) {
        double total = CalculadoraDePrecios.suma(c);
        if (c.size() >= 3) {
            double min = c.stream().mapToDouble(Producto::getPrecio).min().getAsDouble();
            total -= min * 0.50;
        }
        return total;
    }
    public String nombre() { return "Descuento acumulado (3+ productos: 50% al mas barato)"; }
}

// Contexto
class CalculadoraDePrecios {
    private EstrategiaDescuento estrategia = new SinDescuento();
    void setEstrategia(EstrategiaDescuento e) { this.estrategia = e; }
    double calcularTotal(List<Producto> carrito) { return estrategia.calcular(carrito); }
    static double suma(List<Producto> c) { return c.stream().mapToDouble(Producto::getPrecio).sum(); }
}

public class Main {
    static int leerInt(Scanner sc) {
        if (!sc.hasNextLine()) return 0;
        try { return Integer.parseInt(sc.nextLine().trim()); } catch (NumberFormatException e) { return -1; }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        List<Producto> carrito = new ArrayList<>(List.of(new Producto("Mouse", 50), new Producto("Mouse", 50),
                new Producto("Teclado", 120), new Producto("Audifonos", 80)));
        EstrategiaDescuento[] estrategias = { new SinDescuento(), new DescuentoFijo(),
                new DescuentoPorcentual(), new DescuentoPorcentualAcumulado() };
        CalculadoraDePrecios calc = new CalculadoraDePrecios();
        int op;
        do {
            System.out.println("\n===== MENU DE DESCUENTOS =====");
            for (int i = 0; i < estrategias.length; i++) System.out.println((i + 1) + ". " + estrategias[i].nombre());
            System.out.println("5. Agregar producto\n6. Ver carrito\n0. Salir");
            System.out.print("Opcion: ");
            op = leerInt(sc);
            if (op >= 1 && op <= 4) {
                calc.setEstrategia(estrategias[op - 1]);   // se cambia la estrategia en tiempo de ejecucion
                System.out.printf("%s -> Total: S/ %.2f (sin descuento: S/ %.2f)%n",
                        estrategias[op - 1].nombre(), calc.calcularTotal(carrito), CalculadoraDePrecios.suma(carrito));
            } else if (op == 5) {
                try {
                    System.out.print("Nombre: "); String n = sc.nextLine();
                    System.out.print("Precio: "); double p = Double.parseDouble(sc.nextLine().trim());
                    carrito.add(new Producto(n, p));
                } catch (NumberFormatException e) { System.out.println("Precio invalido."); }
            } else if (op == 6) {
                carrito.forEach(System.out::println);
            }
        } while (op != 0);
    }
}

Salida del programa:

1. Sin descuento
2. Descuento fijo (10%)
3. Descuento porcentual (30% en 2 productos iguales)

Opcion: 1..4 (se prueba cada estrategia)
Sin descuento -> Total: S/ 300.00 (sin descuento: S/ 300.00)
Descuento fijo (10%) -> Total: S/ 270.00 (sin descuento: S/ 300.00)
Descuento porcentual (30% en 2 productos iguales) -> Total: S/ 270.00 (sin descuento: S/ 300.00)
Descuento acumulado (3+ productos: 50% al mas barato) -> Total: S/ 275.00 (sin descuento: S/ 300.00)

Explicación: el menú asigna la estrategia con setEstrategia en tiempo de ejecución y la calculadora delega el cálculo, sin if-else. Con el carrito de ejemplo (Mouse 50, Mouse 50, Teclado 120, Audífonos 80 = S/ 300): fijo = 270; porcentual = 35+35+120+80 = 270; acumulado = 300 − 25 = 275. EJERCICIO 3: Control remoto de un televisor (Command)

Enunciado: control remoto con cinco funcionalidades: encender/apagar, subir volumen, bajar volumen, canal siguiente y canal anterior (se agregó además "deshacer").

Rol del patrónClase / interfaz
CommandComando (ejecutar, deshacer)
Comandos concretosEnergia, Volumen (+5 / −5), Canal (+1 / −1)
ReceiverTelevisor
InvokerControlRemoto (botones y historial)

Código (src/ej3_command/Main.java):

package ej3_command;

import java.util.ArrayDeque;
import java.util.Deque;

// Command
interface Comando { void ejecutar(); void deshacer(); }

// Receiver
class Televisor {
    private boolean encendido = false;
    private int volumen = 10, canal = 1;
    void alternarEnergia() { encendido = !encendido; System.out.println("TV " + (encendido ? "ENCENDIDO" : "APAGADO")); }
    boolean cambiarVolumen(int d) {
        if (!estaOn()) return false;
        volumen = Math.max(0, Math.min(100, volumen + d));
        System.out.println("Volumen: " + volumen); return true;
    }
    boolean cambiarCanal(int d) {
        if (!estaOn()) return false;
        canal = Math.max(1, canal + d);
        System.out.println("Canal: " + canal); return true;
    }
    private boolean estaOn() { if (!encendido) System.out.println("(El TV esta apagado)"); return encendido; }
}

// Concrete Commands
class Energia implements Comando {
    private final Televisor tv;
    Energia(Televisor tv) { this.tv = tv; }
    public void ejecutar() { tv.alternarEnergia(); }
    public void deshacer() { tv.alternarEnergia(); }
}

class Volumen implements Comando {
    private final Televisor tv; private final int delta; private boolean aplicado;
    Volumen(Televisor tv, int delta) { this.tv = tv; this.delta = delta; }
    public void ejecutar() { aplicado = tv.cambiarVolumen(delta); }
    public void deshacer() { if (aplicado) tv.cambiarVolumen(-delta); }
}

class Canal implements Comando {
    private final Televisor tv; private final int delta; private boolean aplicado;
    Canal(Televisor tv, int delta) { this.tv = tv; this.delta = delta; }
    public void ejecutar() { aplicado = tv.cambiarCanal(delta); }
    public void deshacer() { if (aplicado) tv.cambiarCanal(-delta); }
}

// Invoker
class ControlRemoto {
    private final String[] etiquetas = new String[5];
    private final Comando[] botones = new Comando[5];
    private final Deque<Comando> historial = new ArrayDeque<>();
    void asignar(int i, String etiqueta, Comando c) { etiquetas[i] = etiqueta; botones[i] = c; }
    void presionar(int i) {
        System.out.println("[Boton " + etiquetas[i] + "]");
        botones[i].ejecutar();
        historial.push(botones[i]);
    }
    void deshacer() {
        if (historial.isEmpty()) { System.out.println("Nada que deshacer"); return; }
        System.out.println("[Deshacer]");
        historial.pop().deshacer();
    }
}

public class Main {
    public static void main(String[] args) {
        Televisor tv = new Televisor();
        ControlRemoto control = new ControlRemoto();
        control.asignar(0, "ENCENDER/APAGAR", new Energia(tv));
        control.asignar(1, "VOLUMEN +", new Volumen(tv, +5));
        control.asignar(2, "VOLUMEN -", new Volumen(tv, -5));
        control.asignar(3, "CANAL +", new Canal(tv, +1));
        control.asignar(4, "CANAL -", new Canal(tv, -1));

        control.presionar(1);   // con el TV apagado no hace nada
        control.presionar(0);
        control.presionar(1);
        control.presionar(1);
        control.presionar(2);
        control.presionar(3);
        control.presionar(3);
        control.presionar(4);
        control.deshacer();
        control.deshacer();
        control.presionar(0);
    }
}

Salida del programa:

Explicación: cada botón del control tiene un comando asignado; el control solo llama a ejecutar() sin saber cómo se hace la acción. Los comandos ejecutados se guardan en una pila (Deque), y deshacer() saca el último y revierte su efecto. Con el TV apagado los comandos no tienen efecto.

EJERCICIO 4: Tienda en línea (Observer + Strategy + Command)

Enunciado: aplicación adicional que combina los tres patrones: las acciones de la tienda son comandos en una cola, el precio se calcula con estrategias intercambiables y los clientes suscritos reciben notificaciones.

Rol del patrónClase / interfaz
ObserverObservador, Cliente (observador) y Tienda (sujeto)
StrategyEstrategiaPrecio, SinDescuento, DescuentoPorcentual, contexto Carrito
CommandComando, AgregarProducto, CambiarPromocion, FinalizarCompra, invoker ProcesadorComandos

Código (src/ej4_combinado/Main.java):

package ej4_combinado;

import java.util.*;

// ===== OBSERVER: los clientes reciben avisos de la tienda =====
interface Observador { void actualizar(String mensaje); }

class Cliente implements Observador {
    private final String nombre;
    Cliente(String nombre) { this.nombre = nombre; }
    public void actualizar(String mensaje) { System.out.println("   [" + nombre + "] " + mensaje); }
}

class Tienda {
    private final List<Observador> clientes = new ArrayList<>();
    void suscribir(Observador o) { clientes.add(o); }
    void desuscribir(Observador o) { clientes.remove(o); }
    void notificar(String mensaje) {
        System.out.println("Tienda notifica: " + mensaje);
        for (Observador o : clientes) o.actualizar(mensaje);
    }
}

// ===== STRATEGY: formas de calcular el precio =====
record Producto(String nombre, double precio) {}

interface EstrategiaPrecio { double aplicar(double subtotal); String nombre(); }

class SinDescuento implements EstrategiaPrecio {
    public double aplicar(double s) { return s; }
    public String nombre() { return "Sin descuento"; }
}

class DescuentoPorcentual implements EstrategiaPrecio {
    private final double pct;
    DescuentoPorcentual(double pct) { this.pct = pct; }
    public double aplicar(double s) { return s * (1 - pct / 100); }
    public String nombre() { return "Descuento " + (int) pct + "%"; }
}

class Carrito {   // contexto de Strategy
    private final List<Producto> items = new ArrayList<>();
    private EstrategiaPrecio estrategia = new SinDescuento();
    void agregar(Producto p) { items.add(p); System.out.println("Agregado al carrito: " + p.nombre()); }
    void setEstrategia(EstrategiaPrecio e) { this.estrategia = e; }
    double total() { return estrategia.aplicar(items.stream().mapToDouble(Producto::precio).sum()); }
}

// ===== COMMAND: acciones de la tienda como objetos =====
interface Comando { void ejecutar(); }

class AgregarProducto implements Comando {
    private final Carrito carrito; private final Producto producto;
    AgregarProducto(Carrito c, Producto p) { carrito = c; producto = p; }
    public void ejecutar() { carrito.agregar(producto); }
}

class CambiarPromocion implements Comando {
    private final Carrito carrito; private final Tienda tienda; private final EstrategiaPrecio estrategia;
    CambiarPromocion(Carrito c, Tienda t, EstrategiaPrecio e) { carrito = c; tienda = t; estrategia = e; }
    public void ejecutar() {
        carrito.setEstrategia(estrategia);                                    // Strategy
        tienda.notificar("Nueva promocion activa: " + estrategia.nombre());   // Observer
    }
}

class FinalizarCompra implements Comando {
    private final Carrito carrito; private final Tienda tienda;
    FinalizarCompra(Carrito c, Tienda t) { carrito = c; tienda = t; }
    public void ejecutar() {
        System.out.printf("Compra finalizada. Total a pagar: S/ %.2f%n", carrito.total());
        tienda.notificar("Se registro una compra en la tienda");
    }
}

class ProcesadorComandos {   // invoker con cola de comandos
    private final Queue<Comando> cola = new LinkedList<>();
    void encolar(Comando c) { cola.add(c); }
    void procesar() { while (!cola.isEmpty()) cola.poll().ejecutar(); }
}

public class Main {
    public static void main(String[] args) {
        Tienda tienda = new Tienda();
        Cliente ana = new Cliente("Ana"), luis = new Cliente("Luis");
        tienda.suscribir(ana); tienda.suscribir(luis);

        Carrito carrito = new Carrito();
        ProcesadorComandos proc = new ProcesadorComandos();
        proc.encolar(new AgregarProducto(carrito, new Producto("Laptop", 2500)));
        proc.encolar(new AgregarProducto(carrito, new Producto("Mouse", 50)));
        proc.encolar(new CambiarPromocion(carrito, tienda, new DescuentoPorcentual(10)));
        proc.encolar(new FinalizarCompra(carrito, tienda));
        proc.procesar();

        System.out.println("\n--- Luis se desuscribe ---");
        tienda.desuscribir(luis);
        proc.encolar(new CambiarPromocion(carrito, tienda, new DescuentoPorcentual(20)));
        proc.encolar(new FinalizarCompra(carrito, tienda));
        proc.procesar();
    }
}

Salida del programa:

Agregado al carrito: Mouse
Tienda notifica: Nueva promocion activa: Descuento 10%
   [Ana] Nueva promocion activa: Descuento 10%
   [Luis] Nueva promocion activa: Descuento 10%

Explicación: CambiarPromocion es un Command que cambia la estrategia del carrito (Strategy) y avisa a los clientes (Observer). FinalizarCompra calcula el total con la estrategia activa y notifica. Cuando Luis se desuscribe ya no recibe avisos, y el total cambia de S/ 2295 (10%) a S/ 2040 (20%) sobre S/ 2550.

CUESTIONARIO

1. ¿Cuál es la ventaja principal de usar el patrón Observer en sistemas con múltiples dependencias?

  • Desacopla al sujeto de sus observadores: el sujeto solo conoce la interfaz Observador, no las clases concretas (Gamma et al., 1994).
  • Cuando cambia su estado notifica automáticamente a todos los dependientes, y estos se pueden agregar o quitar en tiempo de ejecución.

2. ¿Qué problema resuelve el patrón Strategy en comparación con el uso de condicionales como if-else?

  • Evita bloques largos de if-else/switch que hay que modificar cada vez que aparece un algoritmo nuevo.
  • Cada algoritmo vive en su clase, y se agregan nuevos sin tocar el código existente (principio abierto/cerrado) (Gamma et al., 1994).

3. Explica cómo el patrón Command ayuda a desacoplar la lógica de ejecución de las operaciones.

  • Convierte la solicitud en un objeto: el invocador solo llama a ejecutar() y no conoce al receptor ni cómo se realiza la acción.
  • Como el comando es un objeto, se puede guardar, encolar, registrar o deshacer.

4. ¿Qué métodos claves se deben implementar para crear un patrón Observer funcional en Java?

  • En el observador: actualizar(...) (update), declarado en la interfaz.
  • En el sujeto: suscribir (attach), desuscribir (detach) y notificar (notifyObservers), con una lista de observadores.

5. En el patrón Strategy, ¿cómo se puede cambiar dinámicamente la estrategia utilizada?

  • El contexto guarda una referencia a la interfaz de la estrategia y ofrece un método setEstrategia(...).
  • En ejecución se asigna otra implementación; en el Ejercicio 2, el menú cambia la estrategia según la opción elegida.

6. Menciona tres casos de uso donde el patrón Command sería especialmente útil.

  • Interfaces gráficas: botones y menús vinculados a comandos (ej. "Guardar").
  • Deshacer/rehacer en editores o aplicaciones.
  • Colas de tareas, como trabajos de impresión, o automatización de pasos y macros (Horstmann, 2009).

7. ¿Cómo puedes combinar los patrones Observer, Strategy y Command en una aplicación más compleja?

  • Como en el Ejercicio 4: Command encapsula las acciones (agregar, cambiar promoción, comprar); Strategy define cómo se calcula el precio; Observer avisa a los clientes de los cambios.
  • Un mismo comando puede usar a los otros dos: CambiarPromocion cambia la estrategia y notifica a los observadores.

8. ¿Qué ventajas tiene encapsular algoritmos o acciones en clases independientes desde el punto de vista del diseño de software?

  • Menor acoplamiento y mayor cohesión: cada clase tiene una sola tarea.
  • Se pueden reutilizar, probar por separado y extender sin modificar el código existente; los cambios quedan localizados.

9. En el patrón Command, ¿cómo se implementaría la funcionalidad de "deshacer"?

  • Se agrega un método deshacer() a la interfaz Comando que revierte el efecto de ejecutar().
  • El invocador guarda los comandos ejecutados en una pila (historial) y al deshacer saca el último y llama a su deshacer(), como en el Ejercicio 3. Si hace falta, el comando guarda el estado previo (se puede complementar con Memento).

10. Reflexiona sobre cómo los patrones de diseño promueven el principio de responsabilidad única.

  • Observer separa "quién cambia" de "quién reacciona"; Strategy aísla cada algoritmo; Command separa quien pide la acción de quien la ejecuta.
  • Así cada clase tiene una única razón para cambiar, lo que facilita entenderla, probarla y mantenerla.

CONCLUSIONES

  • Observer permite notificar a muchos objetos sin acoplarlos al sujeto; Strategy intercambia algoritmos sin condicionales; Command convierte acciones en objetos que se pueden encolar y deshacer.
  • Los tres patrones reducen el acoplamiento y se pueden combinar, como en la tienda en línea del Ejercicio 4.
